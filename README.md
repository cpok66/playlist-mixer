# Playlist Mixer

Музыкальный плеер для Windows. Собирает треки из SoundCloud, Spotify, Яндекс Музыки, YouTube, Deezer и других сервисов в твои собственные плейлисты, проигрывает их и считает статистику: сколько минут ты слушал, любимый исполнитель, самый слушаемый трек.

## Установка

1. Открой страницу [Releases](../../releases/latest) и скачай **PlaylistMixer.exe**.
2. Положи файл куда удобно (например, в «Документы») и запусти.
3. Если Windows покажет синее окно «Система Windows защитила ваш компьютер», нажми **Подробнее → Выполнить в любом случае**. Так бывает со всеми программами без платной цифровой подписи.

При первом запуске программа сама докачает загрузчик музыки (около 60 МБ) — внизу окна видно, сколько осталось. На рабочем столе появится ярлык.

Python, браузер или что-то ещё ставить не нужно. Окно программы открывается через Microsoft Edge, который уже есть в Windows 10 и 11.

## Обновления

Программа сама проверяет, вышла ли новая версия. Когда выйдет — слева у пункта **«Что нового»** появится метка «новое». Нажми на него и на **«Обновить сейчас»**: программа скачает новую версию и перезапустится. Плейлисты и статистика при этом никуда не денутся.

## Аккаунт

Слева вверху — **«Войти в аккаунт»**. Аккаунт нужен, чтобы плейлисты, статистика и настройки были на любом компьютере: зарегистрируйся здесь, потом войди под тем же логином на другом компе — и там будет всё то же самое. Синхронизация идёт сама, раз в минуту.

Без аккаунта программа тоже полностью работает, просто всё хранится только на этом компьютере.

## Как добавить музыку

Слева нажми **«Добавить музыку»**. Там три вкладки:

**Ссылки и названия.** Вставь ссылки на плейлисты, альбомы или треки — каждую с новой строки, можно из разных сервисов вперемешку. Трек без ссылки можно написать текстом: `Исполнитель - Название`. Выбери, в какой плейлист добавить (или создай новый), и нажми «Добавить». Повторы программа отсеет сама.

**Spotify — аккаунт.** Забирает из Spotify все твои плейлисты и любимые треки целиком. Требует настройки (см. ниже) и Spotify Premium.

**Spotify — файл выгрузки.** Работает без Premium. На [spotify.com/account/privacy](https://www.spotify.com/account/privacy/) отметь «Данные аккаунта» и нажми «Запросить данные». Через несколько дней придёт письмо с архивом `my_spotify_data.zip` — выбери его в программе.

Плейлисты, добавленные по ссылке или через аккаунт Spotify, **связываются с источником**: раз в несколько часов программа сама проверяет их и докидывает новые треки. Под названием плейлиста видно, с чем он связан, и есть кнопка «обновить сейчас».

> Плейлист Spotify больше 100 треков без входа в аккаунт: открой его в приложении Spotify, щёлкни по любому треку, нажми **Ctrl+A**, потом **Ctrl+C** и вставь во вкладку «Ссылки и названия».

## Как играет музыка

Треки с SoundCloud и YouTube играют напрямую. Spotify и Яндекс не дают слушать свою музыку в других программах, поэтому Playlist Mixer находит такой же трек на SoundCloud (а если нет — на YouTube). Трек начинает играть почти сразу и сохраняется в кэш, как у Spotify; следующие треки подгружаются заранее.

Если заиграла не та версия (кавер, ремикс) — правой кнопкой по треку → **«Подобрать другую версию…»**.

Размер кэша (по умолчанию 2 ГБ) меняется в настройках (шестерёнка внизу слева → «Кэш»). Когда место кончается, программа удаляет давно не игравшие треки.

## Текст песни

Кнопка с микрофоном справа вверху открывает панель с текстом. Если есть синхронизированная версия, строки подсвечиваются в такт музыке, а по клику на строку можно перемотать. Иначе показывается текст с Genius. Тексты берутся с Genius и из открытой базы LRCLIB, поэтому у совсем малоизвестных треков текста может не быть.

## Статус в Discord

Программа может показывать в профиле Discord «Слушает Playlist Mixer» с названием трека и обложкой. Настройка: шестерёнка внизу слева → вкладка **Discord**.

Если там написано «Работает сразу» — ничего делать не нужно, главное чтобы Discord был запущен. Иначе:

1. Открой [discord.com/developers/applications](https://discord.com/developers/applications) и нажми **New Application**. Название будет видно в статусе («Слушает …»).
2. Скопируй **Application ID** со страницы General Information и вставь в настройках программы. Нажми «Проверить».

В самом Discord должно быть включено: Настройки → Конфиденциальность активности → «Делиться моей активностью».

## Вход в Spotify (необязательно)

Нужен только для вкладки «Spotify — аккаунт». Spotify пускает сторонние программы через «приложение разработчика», а с 2026 года — только если у тебя есть **Premium**.

1. Открой [developer.spotify.com/dashboard](https://developer.spotify.com/dashboard) и нажми **Create app** (если приложение у тебя уже есть — открой его и нажми **Edit**).
2. Название и описание любые. В **Redirect URIs** вставь точно `http://127.0.0.1:47821/spotify/callback` и нажми **Add**.
3. Отметь **Web API**, согласись с условиями, сохрани.
4. На вкладке **User Management** добавь свой аккаунт Spotify (имя и почту).
5. Скопируй **Client ID** и вставь в программе: шестерёнка → вкладка **Spotify**.
6. «Добавить музыку» → «Spotify — аккаунт» → **Войти в Spotify**. В браузере разреши доступ и вернись в программу.

## Горячие клавиши

| Клавиши | Что делают |
|---|---|
| Пробел | пауза / продолжить |
| Ctrl + → / ← | следующий / предыдущий трек |
| Enter | включить выделенный трек |
| Delete | убрать трек из плейлиста |
| Ctrl + F | поиск |
| Ctrl + N | новый плейлист |

Ещё: правой кнопкой по треку — меню (добавить в другой плейлист, исправить название, подобрать версию), треки можно перетаскивать мышкой на плейлисты слева, по заголовкам столбцов таблица сортируется.

## Если что-то не работает

- **Треки не находятся или не играют.** Проверь интернет. Если у тебя не работает SoundCloud или YouTube без VPN — включи VPN.
- **Программа не открывается.** Убедись, что её не заблокировал антивирус, и попробуй запустить ещё раз.
- **Нужен журнал ошибок.** Он лежит в `%LOCALAPPDATA%\PlaylistMixer\data\log.txt` (вставь этот путь в адресную строку Проводника). Там же хранятся плейлисты и кэш.
